## Механики
- [ ] Поток камней двигается по извилистой трассе без деформации мешей.
- [ ] Бочки движутся на конвейере и открываются однократным тапом/кликом.
- [x] Из бочек появляются работники, монеты и бомба. (Actual mouse + emulated-touch production checks.)
- [ ] Работник устанавливается на свободную открытую площадку и начинает добычу.
- [ ] Работник возвращается в резерв и переносится между площадками.
- [ ] Merge одинаковых уровней работает на ленте и на рабочей площадке.
- [ ] Разные уровни, максимальный уровень и закрытая площадка не вызывают потери объектов.
- [ ] Вид работника при повышении уровня меняется только цветом каски; цифра обновляется.
- [ ] Камень получает урон в момент удара, уничтожается и выдаёт награду один раз.
- [ ] Одновременные удары/бомба не дублируют награды.
- [ ] Покупка площадки проверяет баланс; быстрый повтор не списывает деньги дважды.
- [ ] При заполнении ленты работники/бомбы не исчезают и не занимают одно место вдвоём.
- [ ] Бомба показывает радиус, действует в нём, невалидный сброс возвращает предмет.
- [x] Без debug-кнопок доступны первое объединение и покупка. (Production mouse, оба размера.)
- [ ] Restart возвращает начальное состояние; несколько рестартов не умножают таймеры.

## Мышь / touch
- [ ] Полный игровой цикл пройден мышью.
- [ ] Полный цикл пройден touch-вводом, включая drag, а не только мышью в узком окне.
- [ ] Второй палец не начинает параллельную операцию и не отменяет первый drag.
- [ ] Невалидный drop возвращает предмет на зарезервированный источник.
- [ ] pointercancel/lostpointercapture корректно снимают drag и резервирование.
- [ ] Выход за canvas, потеря фокуса и уход вкладки в фон безопасны.
- [ ] Изменение размера/ориентации во время drag не теряет объект.
- [ ] Тап по UI не проходит сквозь кнопку в игровую сцену.
- [ ] Быстрый двойной тап/повторный pointerup не дублируют предметы, деньги и покупки.
- [ ] Во время игры нет нежелательной прокрутки, выделения текста и браузерного drag.
- [ ] Hit-testing совпадает с картинкой при полях вокруг canvas и разных DPR.
